## Apuração no tempo

```js
const eixo = view(Inputs.radio(new Map([["% de seções apuradas", "apurado"], ["Horário de Brasília (menos confiável)", "hora"]]), {value: "apurado", label: "Eixo horizontal"}));
const medida = view(Inputs.radio(new Map([["% dos válidos", "pct"], ["Votos", "votos"], ["Vantagem", "vantagem"]]), {value: "pct", label: "Medida"}));
```

```js
const titulos = {
  pct: "Participação de cada candidato nos votos válidos já apurados",
  votos: "Votos acumulados de cada candidato",
  vantagem: `Vantagem de ${nomes.petismo} sobre ${nomes.bolsonarismo}, em votos`
};
const inicial = ap.regioes.Brasil.secoes[0] / ap.totais.Brasil.secoes;
const v = validacao;
const faixa = (f) => [Math.min(...v.map(f)), Math.max(...v.map(f))];
const [mediaMin, mediaMax] = faixa((r) => Math.max(r.erro_pct_validos.petismo.media, r.erro_pct_validos.bolsonarismo.media));
const [, maximo] = faixa((r) => Math.max(r.erro_pct_validos.petismo.max, r.erro_pct_validos.bolsonarismo.max));
const [horaMin, horaMax] = faixa((r) => r.erro_pct_apurado.media);
```

<p class="nota">Em 2018 o país votou das 8h às 17h no horário local de cada estado, e o TSE só começou a divulgar os resultados às 19h de Brasília, depois de fecharem as urnas do Acre. Por isso a curva já começa com cerca de ${pct(100 * inicial, 0)} das seções apuradas. ${explicarRitmo(ap, res, nomes)}</p>

<div class="note" label="Sobre a estimativa">

**Como a curva de 2018 é estimada.** Cada seção entra na curva na hora estimada de chegada do seu boletim ao TSE: o encerramento da urna, que o TSE publica, mais o atraso típico (mediana) entre encerramento e chegada na mesma zona eleitoral no mesmo turno de 2022. Sem a zona em 2022, usa-se o atraso do município; sem ele, o da UF. Os votos de cada seção são os reais, dos boletins de urna.

**Quanto o método erra.** Aplicado a 2022, onde a chegada real é conhecida, o método errou em média ${decimal(mediaMin, 2)} a ${decimal(mediaMax, 2)} ponto percentual (no máximo ${decimal(maximo, 1)}) na participação de cada candidato a cada ponto do % apurado. A hora é bem menos precisa: o % apurado em cada horário errou em média ${decimal(horaMin, 0)} a ${decimal(horaMax, 0)} pontos. Por isso o eixo padrão aqui é o % de seções apuradas; detalhes na [Metodologia](./metodologia).

</div>
